# Plan de análisis de concordancia

## 1. Congelamiento
Antes del análisis, congelar la versión de las calificaciones independientes, la rúbrica aplicada y el inventario de casos. Registrar fecha y huellas de integridad.

## 2. Análisis primario
Para dos evaluadores:
- C1-C6: acuerdo exacto y kappa de Cohen ponderado cuadráticamente.
- S: acuerdo exacto y kappa de Cohen no ponderado.
- Informar el número de pares completos y las distribuciones marginales por criterio.
- No imputar datos faltantes.

## 3. Intervalos
Cuando el tamaño de muestra lo permita, estimar intervalos mediante bootstrap pareado por unidad de evaluación. Mantener unidas las calificaciones de ambos evaluadores durante cada remuestreo.

## 4. Adjudicación
Realizar el análisis primario antes de enviar discrepancias al tercer evaluador. Conservar intactas las calificaciones independientes y almacenar las decisiones adjudicadas en un archivo separado.

## 5. Interpretación
Interpretar kappa junto con acuerdo observado, prevalencia, tamaño de muestra e intervalos de confianza. Kappa no sustituye el análisis cualitativo de los desacuerdos.

## 6. Límites de reproducción
Si los formularios independientes no están disponibles, los coeficientes deben identificarse como valores comunicados y no como resultados recalculados a partir de la publicación.
